# 7-Day Fiverr Launch Sprint

Illustrated learning checklist: one sellable skill, three portfolio samples, one Gig, and a system ready for the first order.

**Live page:** https://cod-ies.github.io/todos-for-rafi/

Open the page, tick boxes as you finish them, and keep working about 5–6 hours a day. Progress is saved in that browser only.

The page is in **English** and **Dari (دری)**. Use the EN / دری switch, or open [the Dari version](https://cod-ies.github.io/todos-for-rafi/?lang=prs).

The week does not promise page-one ranking. It prepares a beginner to serve the first client without avoidable cancellations or poor reviews.
